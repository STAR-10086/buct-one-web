## [0.3.6] - 2026-11-24

### 新增
- **北化在线独立课程模块（`TheolCourseActivity` / `TheolCourseDetailActivity`）与课件资源浏览**：
  - 工作台新增独立「北化在线 · 课程与资源」卡片（支持 Mini / Medium / Large 三种尺寸，原「北化在线」卡片调整为「作业待办」以区分职责）；
  - 通过 `blen.student.lesson.list.jsp` 拉取全部在读课程（突破首页 20 门限制）并支持顶部关键词实时搜索；
  - 进入具体课程可切换「单元学习」与「课程资源」，支持单元多文件列表与单文件直出页解析、多级子目录展开；点击文件行直接在 App 内在线预览（MP4 / PPT / PDF 等），点击右侧下载图标走原生会话下载并用本机应用打开（`TheolParser parserVersion: 6 → 7`）。
- **作业与考试表格批量导入及标准模板分享（`TaskImportActivity`）**：
  - 支持解析 Excel（`.xlsx`）与 CSV 任务表格，自动识别课程、标题、DDL 与提交方式并按紧急度着色，支持审核后批量写入本地待办与智能提醒；
  - 内置标准模板下载与系统分享，并在校园邮箱附件中支持一键直达表格导入。
- **培养方案多级树状结构与一键展开交互**：
  - 培养方案页面按真实父子层级展示树形缩进与连接线，区分可展开节点（旋转箭头 + 子模块/课程数提示）与不可展开末端节点（圆点标识），并支持一键「全部展开 / 全部收起」。

### 优化与修复
- **恢复全应用预测性返回手势**：北化在线二级课程中心、单元详情与子目录改用独立 `TheolCourseDetailActivity` 承载，享受系统级跨 Activity 预测性返回动画；修复 `TheolSubmitWebViewActivity`、`CookieWebViewActivity`、`AcademicWebViewActivity` 在首页无条件拦截返回导致预测性返回失效的问题。
- **修复北化在线课件下载权限预热与误报**：下载前按需跳过冗余 `hwtask.jsp` 激活并预热 `download_preview.jsp`，精确识别错误页与 JS `alert(...)` 提示，会话失效时自动触发静默重登重试。
- **修正 4.33 绩点换算表、GPA 上限及合格课程学分统计**。
- **优化作业页顶栏布局**：移除多余文件夹入口，合并「新建本地待办」与「从表格批量导入」为统一的 `+` 弹窗菜单。
- **清理已落地功能的历史规划文档**，同步更新路线规划、`README.md` 与 `AGENTS.md`。

## [0.3.5] - 2026-11-24

### 新增
- **新增「今日课表·卡片」「待办事项」「考试倒计时」与「校园卡/电费余额」桌面小组件（原「今日课表」组件原样保留，多款并存）**：
  - **今日课表·卡片按桌面尺寸自适应**：最小 2×1 时只放一堂课（默认「下一节课」，点卡片左右两端的箭头翻看当天前后课程），拉到 4×2 及以上自动换成当天完整课程列表；两种形态都只显示课程名称、上课教室、上课时间三项，单行放不下用省略号截断，列表放不下可上下滑动；
  - **待办事项小组件（最小 2×1）**：合并北化在线的「待交作业」与「未完成测验」两个数据源，汇总成「还有未完成任务的课程名称」，一行一门课并标注作业 / 测验条数，按最近截止时间排序，超出可上下滑动，点击直达作业页；
  - **考试倒计时与余额信息卡小组件**：新增考试倒计时小组件（展示近期考试倒计时、时间与考场）及校园卡 / 宿舍电费双余额信息卡小组件；
  - **尺寸解析与缩放适配统一收敛到 `WidgetSizePolicy`**：兼容部分桌面只写 AppWidgetOptions 的 min 或 max、横竖屏含义互换、API 31 以下无 `setViewLayoutWidth` 的降级路径，尺寸变化立即重排布局、行高与字号。
- **本地智能提醒双引擎与「通知体检与即时测试」页**：
  - 基于 `AlarmManager` 精准定时 + `WorkManager` 周期后台巡检实现本地智能提醒（零后台保活常驻），支持独立开关与提前量配置：作业 / 测验 DDL 提醒、考试倒计时、图书应还、校园卡低余额与宿舍电费低余量 5 类提醒；
  - 针对小米澎湃 OS / vivo OriginOS / OPPO ColorOS / 荣耀 MagicOS / 华为鸿蒙 / 三星 OneUI / 魅族 Flyme 等国产系统提供「自启动与后台耗电设置」直达入口与 10 秒延迟通知测试页。
- **成绩页累计 GPA 折线图、目标 GPA 模拟器与重修/补考徽章**：
  - 新增纯 Compose `Canvas` 绘制的学年 / 学期累计 GPA 趋势折线图与目标 GPA 所需绩点模拟器；
  - 总体与学期成绩卡片课程名旁新增「重修 / 补考 / 缓考」状态徽章。
- **校园卡消费趋势与商户分类洞察**：
  - 基于本地同步流水绘制消费趋势折线图与商户类别（餐饮 / 超市 / 洗浴水控 / 其他）占比分布，零第三方图表库。

### 优化与修复
- **按北化教务官方口径精准对齐累计 GPA 计算与重修/补考分项校验**：
  - 保留 `PHE` 前缀的军事技能与军事理论课（仅排除课程名含「体育」、素质教育及两级制课程）；
  - 按课程去重取最高绩点（补考通过按 `1.0` 兜底，多次挂科仅计一次学分，重修按新成绩覆盖旧挂科记录），`parseGradesJson` 优先读取 `MAXCJ`；
  - 新增按加权占比自动校验分项明细（`isDetailConsistentWithGrade`），彻底清除重修成绩误套旧挂科平时/期末分项的问题，并归一化学年/学期编码（`3`/`12`/`16` 与 `1`/`2`/`3`）防止缓存分项丢失。
- **修复教务连接复用 `unexpected end of stream` 断流报错并保护缓存**：
  - `CourseApiClient` 拦截到 `unexpected end of stream` / `EOFException` / `Connection reset` 等瞬时断流时自动清空连接池并携带 `Connection: close` 重试；
  - `GradesRoute` 跳过两级制、未出分与补考等无分项课程的冗余请求，并在学期成绩与考试安排请求前先加载本地缓存兜底，失败绝不清空已有数据。
- **修复北化在线测验课程名被误解析为「在线」的问题**（`TheolParser parserVersion: 5 → 6`）。
- **修复作业实验报告与实践教学列表重复主键导致 Compose 闪退的问题**（`SjcxParser parserVersion: 1 → 2`）。
- **加固发版工作流同步 `buct-one-web` 官网仓库脚本**：兼容 deploy key 的 base64 / CRLF 格式并放宽 GitHub SSH `known_hosts` 密钥类型扫描与接收策略。

## [0.3.4] - 2026-11-23

### 新增
- **校内受限域直连优先 WebVPN（`w.buct.edu.cn`）自动降级与 2FA 认证**：
  - 针对仅限校内网访问的 7 个域名（第二课堂 `scs.buct.edu.cn` / `eapi.buct.edu.cn`、校园卡 `ecard.buct.edu.cn`、研究生系统 `gmis.buct.edu.cn`、i北化 `i.buct.edu.cn` / `mnews.buct.edu.cn`、校园网网费 `tree.buct.edu.cn` 含 `:8800` 端口）实现 `BuctWebVpn`（Wengine AES-128-CFB URL 编解码 + `BuctWebVpnInterceptor` / `BuctWebVpnNetworkInterceptor`）；校外可直连域名（`jwglxt`、`course`、`tygl`、`sjcx`、`mail`、`sidportal`、`ele.buct.one`）全程保持直连不走 WebVPN；
  - 按域名独立维护 3s 直连优先探测（校园网 Wi-Fi 下直接直连），校外遇到 DNS 不可达、连接超时或校方防火墙 403/VPN 提示页时自动通过 `sidportal` 换取并持久化 `wengine_vpn_ticketw_buct_edu_cn`（存入 `SidPortalSessionVault` Keystore 加密存储）；
  - 支持原生 `BuctSsoLoginManager.loginWebVpn()` 短信二次验证（2FA）与网页认证双通道激活 WebVPN 票据。
- **宿舍电费查询（`ele.buct.one`）**：
  - 新增独立 `ElectricityActivity` 与工作台 `ELECTRICITY` 卡片（`parserVersion: 1`），内置全校昌平 / 东区 / 西区离线宿舍字典，支持东区同房间「照明 + 空调」双表一键绑定、低电量阈值提醒与 15 分钟边缘缓存；
  - 接入随请求签名的 `X-Student-Id` 防滥用机制，首次使用展示学号共享说明并在查询/设置页顶部常驻提示（支持随时撤回授权并清除绑定），演示模式不触发上传。
- **北化校园网网费与账单免密查询（`tree.buct.edu.cn`）**：
  - 新增独立 `CampusNetActivity` 与工作台 `CAMPUS_NET` 卡片（`parserVersion: 2`），通过深澜网关与 `:8800` 自服务平台（直连优先 + 校外 WebVPN 自动降级，异常时支持一键跳转 WebVPN 认证）免密查询账户状态、本月消费、产品余额、电子钱包、周期已用流量、在线终端、缴费清单与月度结算账单，遵循「失败保留旧快照」铁律。

### 优化与修复
- **统一全端 `sidportal` 请求 User-Agent 并加固根凭证存储**：统一 7 个 SSO 子模块与 `BuctWebVpn` 访问 `sidportal.buct.edu.cn` 时的 `User-Agent`，确保一次登录签发的 `SOURCEID_TGC` 跨模块免密复用；`SidPortalSessionVault` 增加 `SOURCEID_TGC=` 校验守卫，防止未完成认证或 2FA 中间态的 `SESSION` 覆盖有效根凭证；各子模块在认证页缺失 `execution`/`croypto` 时自动清 Cookie 重试并准确识别 `#sso-second` 二次验证状态。
- **空闲教室与选课抢课改为独立 Activity**：工作台「空闲教室」与「选课抢课」入口独立为 `EmptyClassroomActivity` / `CourseSelectionActivity`（`GlassWindowHost`），获得系统级 Android 14+ 预测性返回手势动画。
- **修复作业页顶栏「后台同步中…」副标题截断省略**。
- **移除登录后旧版多校教务功能引导页**：统一身份认证登录后直接进入主工作台/课表界面。
- **CI 构建提速与 `dev-latest` 滚动预发布**：非发版提交仅编译 `arm64-v8a` 并自动更新 GitHub Releases `dev-latest` 滚动测试包，移除预发行构建对 Cloudflare R2 的上传。
