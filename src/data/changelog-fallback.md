# Changelog

所有面向用户的实质性功能新增、问题修复与架构演进记录如下，版本格式遵循 Keep a Changelog。

## [Unreleased]

### 新增
- **工作台 2D 自由栅格自定义**：4 列 × N 行真实 2D 坐标骨架，支持 2×1 大卡片、1×1 中卡片、0.5×0.5 迷你小卡片自由混排，长按弹簧拖拽与箭头调尺寸；编辑态顶栏固定，支持最多 30 步撤回。
- **选课与抢课集成**：工作台新增直达「选课抢课」入口，优化非选课开放阶段的教务提示。
- **第二课堂原生接入**：通过 sidportal CAS 换取 JWT，原生查看五育（德/智/体/美/劳）综测成绩、分类明细、自评窗口状态与二课活动记录。
- **智能混合校内 DNS（BuctDns）**：校内业务优先直连校内 DNS 并在超时后回退系统 DNS，兼顾校内外访问体验。
- **「我的」个人名片与权限管理**：自定义头像、个性签名与展示昵称；新增系统通知与精确闹钟权限自检弹窗。

### 优化与修复
- **HyperOS 4 桌面小组件修复**：无标题布局、按实例隔离偏移存储、局部增量刷新解决翻页回跳，20dp 圆角背景与矢量翻页图标。
- **北化在线两阶段后台静默同步（parserVersion 4 → 5）**：第一阶段快速刷新待交作业与测验，第二阶段后台补齐全部在修课程作业，不阻塞作业详情与附件下载。

## [0.2.0] - 2026-11-19

### 新增
- **北化一站（BUCT One）架构成型**：确立 com.buct.one 单 module 分层数据内核（model / session / source / store / sync），遵循失败保留旧快照等四条数据铁律，落地 code-check 静态门禁与 build-apk（100MB 体积门禁 + 正式发布签名）云端工作流。
- **全原生统一身份认证**：原生 Kotlin 实现 sidportal.buct.edu.cn 登录（SM2/AES + 短信二次验证 + Passkey/WebAuthn，无 WebView 登录），支持本科与研究生教务，并由 Android Keystore（AES-GCM）隔离存储凭据。
- **教务核心体验**：周视图/日视图课表、自定义课程与课前提醒、ICS 日历导出、分学期/培养方案成绩与考试倒计时、空闲教室查询。
- **桌面小组件**：周课表与可滚动的今日课表小组件（最小 2×2），同步开学第一周与三学期配置，今日课表按当前时间自动隐藏已结束课程。
- **北化在线（THEOL/MEOL）**：免二次登录拉取待办作业与测验，原生预览作业要求、原生下载打开附件及复用会话的 WebView 交作业。
- **实践教学与校园一卡通**：接入实验课表、抢讲座/写心得与创新学分，以及独立登录的校园卡余额与消费流水查询。
